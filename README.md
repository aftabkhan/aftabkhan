### JobFit

**JobFit** is an evidence-led resume-tailoring Chrome extension built as a standalone working MVP.

It can:

- Parse an uploaded DOCX resume into a protected evidence model
- Read active job-detail pages with generic and platform-aware extraction
- Dynamically identify role-specific JD requirements
- Classify direct, transferable and unsupported evidence
- Surface recruiter risks and truthful gaps
- Tailor permitted resume content while preserving employment facts
- Generate ATS-safe DOCX resumes
- Track applications, source CVs, job URLs and generated resumes
- Fall back to manual JD input when a site blocks extraction

The project includes documented QA, regression testing, integrity checks, responsive UX, validation states, loaders and accessibility-focused interaction patterns.
